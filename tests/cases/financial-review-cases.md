# Advice V2 金融内容评审用例

## 目标

验证生成内容是否对人工判断有意义，而不是验证自动执行或历史盈利能力。

| ID | 场景 | 期望 |
|---|---|---|
| ADV-001 | 4h/1h 偏多，附近有跨周期支撑 | 只形成一个 `WATCH_LONG`，含关注区和做多确认清单。 |
| ADV-002 | 4h 与 1h 方向相反 | 返回 `WAIT`，不强行选择方向。 |
| ADV-003 | 行情快照陈旧 | 返回 `AVOID`，不保留候选方案。 |
| ADV-004 | 止损位或目标位穿越关注区 | 确定性审计失败并降级。 |
| ADV-005 | LLM 输出新价格或无中生有的方案 | 拒绝 LLM 文案，保留确定性结果。 |
| ADV-006 | 报告导出 | 只有 Advice V2 字段，不含 V1 决策链。 |

人工复核重点：建议是否能用一句话说清方向；是否明确“现在做什么/不做什么”；确认条件是否可观察；失效条件是否可证伪；风险和不确定性是否与结论分离。

执行命令：

```powershell
python -m pytest tests/unit/test_advice_v2.py -q
python tests/tools/financial_review_run.py
```
