# 项目定义

GoldAnalysisAI 当前产品目标是为 XAUUSD 生成可由人审核的交易建议，不自动执行交易。

## 范围

- 获取多周期行情与外部背景。
- 计算指标和 PA/ICT/SMC 结构事实。
- 生成最多一个首选关注方案，或明确返回 `WAIT` / `AVOID`。
- 提供关注区、确认清单、失效位、目标、证据、风险和不确定性。
- 保存运行归档并支持不联网回放。
- 可选使用一次 LLM 文案增强，数字和方向不可修改。

## 非当前范围

- 自动下单、仓位管理、券商执行和交易授权。
- 多 Agent 辩论、投票或 Manager 决策链。
- 对历史胜率、收益或盈利能力的承诺。

当前架构与重构处置见 [Advice V2 评审记录](../aspice/records/reviews/financial/advice-v2-rearchitecture-2026-08-12.md)。
