# Advice V2 审计计划

## 审计目标

验证建议可追溯、可证伪、不会越权为执行指令，并能在数据或模型失败时安全降级。

| 审计面 | 检查内容 | 失败处置 |
|---|---|---|
| 数据时效 | data-as-of、未来数据、闭市与陈旧状态 | 返回 `AVOID` 或明确警告 |
| 方向 | 4h/1h 一致性与 15m 上下文 | 冲突时 `WAIT` |
| 关注区 | 是否来自跨来源或跨周期结构共振 | 孤立水平不形成方案 |
| 几何 | BUY/SELL 的关注区、失效位和目标顺序 | 审计失败降级 `AVOID` |
| 证据 | setup 引用的 evidence ID 是否存在 | 审计失败 |
| 人工确认 | 是否有可观察清单和当前状态 | 缺失时审计失败 |
| 外部背景 | 新闻和日历是否只作风险提示 | 禁止直接创造价格点位 |
| LLM | 是否只改文字，是否引入新价格或方案 | 拒绝并回退确定性结果 |
| 报告 | V2 必需字段和 V1 禁止字段 | 阻止发布 |
| 归档 | 配置、步骤、审计、数据与回放一致性 | 明确 degraded/incompatible |

## 证据

主要自动化证据来自 `tests/unit/test_advice_v2.py`、归档测试、LLM 策略测试、样例回归和 ASPICE 双向追溯。运行结果记录在 `docs/aspice/records/verification/`。
