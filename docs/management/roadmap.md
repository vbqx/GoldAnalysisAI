# 产品路线图

## 当前基线：Advice V2

- 单一人工审核建议契约。
- 高周期方向、附近结构共振、确认清单、失效与目标。
- 确定性审计和可选单次 LLM 文案增强。
- V2 归档与 V1 数据重建回放。

## 下一阶段：建议质量校准

1. 建立人工审核标签：有用、模糊、过早、错方向、失效定义不清。
2. 保存建议生成时的事实快照与人工确认结果。
3. 用冻结历史截点评估 WAIT/AVOID 比例、建议稳定性和几何合理性。
4. 调整共振阈值、距离、波动缓冲与目标空间规则。

## 后续候选：人工批准后的执行

执行能力只有在 Advice V2 建议质量稳定、人工审批模型和风控边界另行建立后才进入设计。届时应作为新需求和新安全架构，不复用已经退役的 V1 Manager 授权语义。
