# 当前状态

最后更新：**2026-08-12**

## 已完成

- 主链已重构为 Advice V2：行情 → 指标 → 结构事实 → 单一建议 → 确定性审计 → 报告 → 归档。
- 输出只面向人工确认，不包含下单、仓位授权或自动执行。
- 建议最多包含一个关注方案，明确方向、关注区、失效条件、最多两个目标、证据和确认清单。
- LLM 只做受约束的中文解释润色，不能修改方向、价格、目标或证据。
- V1 的多 Agent、辩论、交易员、风险经理、报告可信度拼装和回测主链已从当前代码删除；Git 历史保留追溯。
- 旧归档可用保存的行情与结构事实重建 Advice V2；回放不重新联网或调用 LLM。
- ASPICE SWE.1–SWE.6 已切换到 Advice V2，并由机器证据和链接检查维护。

## 当前边界

- 产品提供研究建议，不声称盈利概率，也不代替人工判断。
- 外部新闻和宏观数据只作为背景与风险提示，不单独决定方向。
- 实时数据源可能受网络和供应商状态影响；过期或低质量数据会使建议降级。
- MT5 仅保留连接自检能力，交易执行是后续独立阶段，不属于本基线。

## 下一阶段

1. 用多组历史归档建立建议质量评测集，重点检查“等待是否合理”和“关注区是否可执行”。
2. 增加人工反馈记录：接受、拒绝、原因和后续市场结果，但不自动下单。
3. 在明确评测指标后再设计 shadow execution；执行能力不得反向污染建议生成边界。
