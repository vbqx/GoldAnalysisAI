# Advice V2 术语

| 术语 | 含义 |
|---|---|
| Advice V2 | 当前人工审核建议契约，`artifact_version=2`。 |
| 关注区 | 等待价格到达并由人工观察确认行为的区间，不等于自动入场。 |
| 确认清单 | 可由人观察的 5m 价格行为条件。 |
| 失效位 | 使当前首选方向不再成立的结构价格。 |
| 首选方案 | 一次输出最多一个的多或空关注方案。 |
| `WAIT` | 数据可用但证据不足，不形成首选方案。 |
| `AVOID` | 数据或审计不合格，本次避免使用建议。 |
| evidence ID | 建议引用的稳定结构事实标识。 |
| 置信等级 | 证据质量的 low/medium/high，不是回测胜率。 |
| 人工审核 | 用户在执行前自行核对价格行为、风险事件与有效性。 |
