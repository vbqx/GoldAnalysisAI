# Advice V2 界面验收记录（2026-08-12）

## 范围

验收主建议页、生成配置、外部数据页、**LLM 思考过程** 审计页和历史回放入口。V1 的短线策略页和多 Agent **决策链** 页已移除。

## 验收项

| 项目 | 结果 |
|---|---|
| 主视图只显示一份人工审核建议 | 通过 |
| 显示 WAIT / WATCH_LONG / WATCH_SHORT / AVOID | 通过 |
| Watch 方案显示关注区、当前状态、确认清单、失效位和目标 | 通过 |
| 证据、风险、不确定性和审计结果可展开查看 | 通过 |
| 明确声明系统不自动执行交易 | 通过 |
| 确定性和 LLM 文案增强两种生成方式可选 | 通过 |
| 回放不触发新抓取或 LLM，旧归档重建 V2 | 通过（自动化契约） |
| LLM 思考过程页展示生成步骤、LLM I/O 与 advisor_trace | 通过（单元测试 + 契约） |
| 生成等待面板可流式显示 LLM 输出 | 通过（单元测试） |
| 外部数据独立显示，不直接产生入场价 | 通过 |

## 运行方式

交互复核使用 `python run_app.py`，默认地址 `http://localhost:8501`。本记录覆盖契约和页面结构；不同浏览器宽度的像素级截图可在发布候选阶段补充。
